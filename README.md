# klinfits

One-page site for Klinfits Drop 01. Clean is the standard.

Start with [CLAUDE.md](CLAUDE.md) and [klinfits-handoff/HANDOFF.md](klinfits-handoff/HANDOFF.md).

## Fonts

The font files are not in this repo: their licence (ITF Free Font License) does not allow sharing them through a public repository. Download Clash Display (Medium, Semibold) and Switzer (Regular, Medium, Semibold) from [fontshare.com](https://www.fontshare.com) and put the `.woff2` files in `assets/fonts/` (and `klinfits-handoff/public/fonts/` for the handoff).
