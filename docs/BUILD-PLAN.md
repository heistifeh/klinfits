## 2. Tokens

`scripts/build-tokens.mjs` merges `klinfits-handoff/design/tokens.json` with `tokens/extra.json` and writes `app/theme.css`.
- It resolves aliases such as `on-silver: "{black}"`.
- An entry in `extra.json` must say `"override": true` to replace an existing token, so collisions are deliberate.
- `extra.json` can later be copied into the claude.ai design system so both stay in sync.

**theme.css shape:** `--color-*: initial` and `--radius-*: initial` first, so Tailwind's default palette and radii are gone. Then the 14 colours, 4 radii, `--spacing-section: 120px`, two container widths, and every type style as `--text-<name>` with its `--line-height`, `--font-weight` and `--letter-spacing`.

**Usage:**
- `bg-carbon`, `text-ash`, `rounded-tile`, `py-section`, `max-w-content`, `text-display-hero`.
- Tailwind's 4px spacing steps already equal the handoff's `space-N` tokens: `p-4` = 16, `p-8` = 32, `pt-22` = 88. The design's other spacings (40/32 tile padding, 36 step padding, 64/104 hero padding, 48 CTA padding) are all on the same 4px grid.
- Tailwind exposes every token as a CSS variable, so custom CSS uses `var(--color-silver-300)` and never a hex.

**Named tokens added in `tokens/extra.json` (values from the design file):**

| Token | Value | Used for |
| --- | --- | --- |
| `display-hero` (override) | `clamp(3.5rem, 2.1rem + 5.6vw, 7rem)`, lh 0.95, -0.01em | "Look good. Train easy." (56 → 112px; the token said 120) |
| `display-section` (override) | `clamp(2.75rem, 1.9rem + 3.6vw, 4.5rem)`, lh 1 | Sizes and order headings (44 → 72px) |
| `display-band` | `clamp(2.25rem, 1.7rem + 2.2vw, 3.5rem)`, lh 1 | "Built for the session." (36 → 56px) |
| `display-sub` (override) | `clamp(2rem, 1.6rem + 1.6vw, 2.75rem)`, lh 1 | "Only 14 in Drop 01." (32 → 44px) |
| `advice` | 19px, lh 1.5, 400 | Sizes paragraph |
| `price` | 21px, lh 1.2, 500 | Hero price |
| `note` | 14px, lh 1.3, 500 | Stock line, badge value, nav CTA (with semibold) |
| `micro` | 12px, lh 1.4, 400 | Global bar note, "On me", footer note |
| `step` | 15px, lh 1, 600 | Step circle numbers |
| `container-content` | 1180px | Section width |
| `container-bar` | 1024px | Global bar and sticky nav width |

The exact clamp numbers get tuned in step 2 so they hit the design's sizes at 390 and 1440px. All of them use `rem` plus `vw`, so they still grow at 200% browser zoom.

**Silver utilities in globals.css:**
- `bg-silver` and `text-silver` both use `linear-gradient(100deg, var(--color-silver-100) 0%, var(--color-silver-300) 45%, var(--color-silver-500) 100%)`. `text-silver` adds `background-clip: text`.
- `@media (forced-colors: active) { .text-silver { color: CanvasText; background: none } }`.
- Contrast: the darkest stop, #7A7A7A on black, is 4.9:1. The display text only needs 3:1.

## 3. Fonts

- `app/fonts.ts` uses `localFont` with `src` arrays pointing at `../assets/fonts/*.woff2`, `display: 'swap'`, `variable: '--font-clash'` / `'--font-switzer'`, and the fallback stacks from tokens.json.
- The variables go on `<html>`. `globals.css` maps them in `@theme inline` to `--font-display` and `--font-sans`, and `font-sans` is the body default.
- next/font/local copies the files unchanged into `/_next/static/media/` and preloads them. It does not subset or convert them, which the licence forbids. No font processing gets turned on.
- **Gate:** the font files are only committed after `gh repo view heistifeh/klinfits --json visibility` returns `PRIVATE`.
  - That commit also replaces the `*.woff2` ignore rule with one for `klinfits-handoff/public/fonts/` only, so a single copy lives in the repo.
  - It updates the font lines in CLAUDE.md and README.md as well.

## 6. Size picker

- `SizePicker` owns `useState<SizeId>(defaultSize)`. React is the source of truth; GSAP only animates between states.
- Built now with the hooks motion needs later: a separate indicator pill moved by `--i` and `translateX`, every number going through `RollingNumber`, and a `ref` plus `data-size` on the thumbnail.
- **Sold out (stock 0):**
  - The pill stays a selectable radio (`role="radio"` with `aria-checked`).
  - It shows the size letter with "Sold out" under it in 12px (`micro`). A pill reading only "Sold out" wouldn't say which size, and two sold-out sizes would look the same.
  - Its accessible name is "S, sold out".
  - When it's selected, the "In Drop 01" cell spans the full grid width and reads "Sold out. DM to be first for the next drop." The measurements stay visible.
- **Step 13 adds motion in two places only:**
  - `useSizeMotion(rootRef, selected)` slides the indicator over 0.45s ease-out and scales the thumbnail to about 0.96 / 1 / 1.04.
  - `RollingNumber` animates from the old number to the new one through its `ref`. React has already set the final text, the animated digits are `aria-hidden`, and a visually hidden copy holds the real value.
  - Picking a sold-out size skips the stock roll.

## 7. Motion

- **Registration:** `lib/gsap.ts` (`'use client'`) registers ScrollTrigger and useGSAP once. Only client components import it.
- **Cleanup:** every animation lives in `useGSAP`. On unmount or hot reload it undoes its tweens and ScrollTriggers.
- **Reduced motion:**
  - Animations are only created inside `gsap.matchMedia().add('(prefers-reduced-motion: no-preference)', …)`, and the media query is reverted on cleanup.
  - CSS under `prefers-reduced-motion: reduce` turns off the indicator transition and the shimmer, and the pressed state keeps the opacity change but drops the scale.
- **No flash before the hero animation:**
  - The inline head script adds `motion-ok` only when motion is allowed, and CSS hides `.motion-ok [data-anim="hero"]` until GSAP fades it in.
  - Only the text column fades; the hero photo never does, so the page's main load-speed metric (LCP) isn't delayed.
- **What runs:**
  - Hero fade-up: 0.7s.
  - Tiles rising: `[data-anim="rise"]`, ScrollTrigger `start: 'top 85%'`, `once: true`, 0.6s ease-out, a short stagger.
  - Silver button shimmer: `[data-anim="shimmer"]`, every few seconds.
- **After fonts load:** `document.fonts.ready.then(() => ScrollTrigger.refresh())`.

## 10. Risks

1. **The fonts must not reach a public repo.** The repo is public today. Step 1 checks visibility first and stops if it isn't private.
2. **DM links depend on the platform.**
   - Instagram works: `https://ig.me/m/<handle>`.
   - TikTok has no public link that opens a DM, so the best available is the profile (`https://www.tiktok.com/@<handle>`).
   - X's DM link needs the account's numeric user ID, not the handle (`https://x.com/messages/compose?recipient_id=<id>`), and only works if DMs are open to everyone.
3. **The order heading is only true once stock lands.** "No waiting weeks for a parcel." promises local stock, so it's tagged `UPDATE WHEN STOCK LANDS`, like the hero line about Nigeria in HANDOFF.md.
   - At phone size, "NO WAITING WEEKS" is about 420px wide at 44px, so the heading runs to 3 lines on a 390px screen.
4. **The design and tokens disagree.** Handled by `tokens/extra.json`, with the design file winning. Header borders follow the design (carbon) rather than the brand book (steel).
5. **Display sizes and zoom.** The design's `vw`-only clamps don't grow with browser zoom. The `rem` + `vw` clamps fix this; step 2 checks them.
6. **The logo needs tidying.** The lockup has a black background with no transparency, so it relies on `mix-blend-mode: lighten` against graphite. The mark is wider than tall, so it's about 57px wide at 32px tall.
7. **Copy will go stale.** All stale-able lines are tagged in `drop01.ts`. When everything sells out, the "Only 14" block has no copy yet.
8. **`mood-gym.jpg` is low resolution.** It's portrait, 1206px wide, so it's enlarged about 1.2× at 1440px and 1.6× at 1920px. The black overlay hides most of the softness. It shows a tank top, not the tee.
9. **Photo shape.** The brand book's photo stage is 16:10, but the design and HANDOFF use 4:5. The design wins.
